# ADR-0001：采用 Clean Slate 重构

状态：已接受
日期：2026-08-27

## 背景

旧系统围绕本地 OCR、本地规则、旧数据库和逐步兼容演进。新产品的核心变为 AI 候选、证据、确定性校验和人工审核。继续兼容旧结构会把旧模型、旧迁移和双写带入新架构。

## 决策

- 新系统不读取、不迁移旧数据。
- 不兼容旧数据库、API、任务状态、部署或前端。
- 新数据库从 `0001` 开始，新 API 从 `/api/v1` 开始。
- 旧实现只作为需求参考，不是新代码依赖。
- 旧版本保留为历史 Release，不提供升级承诺。

## 结果

### 正面

- 新架构不承担兼容分支和数据清理负担；
- 可以把审核和追溯建成系统不变量；
- 测试、部署和文档只描述一个当前系统。

### 代价

- 旧用户不能原地升级或保留数据；
- 新系统必须重新完成全部核心业务验收；
- 旧代码不能被当作“已经实现”的捷径。

## 禁止的回退

不得以临时工具、隐藏入口或一次性脚本名义重新引入旧数据导入。若未来改变本决策，必须新建 ADR 并重新审查完整架构和验收边界。
