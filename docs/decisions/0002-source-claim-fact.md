# ADR-0002：采用 Source、Claim、Fact 数据边界

状态：已接受
日期：2026-08-27

## 背景

AI 输出可能不完整、冲突或错误。让模型直接修改支付、发票和行程会使错误来源、修订过程和审核责任不可追溯。

## 决策

- Source 保存不可变原始文档和派生页面身份。
- 模型产生带类型的账单业务 JSON 与可见来源；AI 处理阶段通过唯一的薄 Claim Mapper 产生版本化 Claim 和 Evidence。
- 本地确定性规则产生 ValidationResult。
- M1 只有用户明确确认后才能以一个事务创建 Fact。
- AI 原始值、用户修订和 ReviewDecision 全部保留审计链。
- 不展示或依赖模型自报数字置信度。

## 结果

- AI 错误不能直接污染正式数据；
- 正式字段可以追溯到原件和审核决定；
- 自动入账必须作为未来独立风险决策，而不是调整一个阈值。

## 禁止的回退

- AiRun 或 Claim handler 直接写 Fact；
- UI 绕过服务端 Validation；
- 用默认值把无效模型响应变成成功；
- 原地覆盖 AI 原始 Claim。
