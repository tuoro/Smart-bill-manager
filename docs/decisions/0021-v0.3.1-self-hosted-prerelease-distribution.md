# ADR-0021：v0.3.1 自托管预发布分发

状态：已实施

日期：2026-09-01

## 背景

ADR-0019 证明了本地发布候选的内容、运行时与质量门禁，但其构建流程依赖受保护的本机离线产物，不能作为普通使用者的部署入口。`v0.3.0` 已公开源码和 Tag；若没有可拉取镜像、面向用户的 Compose、凭据初始化工具和最短部署路径，Release 仍不具备可复现的自托管实测能力。已发布 Tag 不重写，因此部署修复作为 `v0.3.1` 补丁预发布交付。

## 决策

- 将已通过 M4 门禁、由发布输入摘要 `01f1fe49a26ce4d50742ae2aba17965d1fccb9a5c8fbd108ac1526e74539187b` 标识的候选发布为 `ghcr.io/tuoro/smart-bill-manager:v0.3.0`。部署修复版 `v0.3.1` 直接固定该 manifest digest，不复制镜像标签。首个分发制品只支持 `linux/amd64`，不发布或覆盖 `latest`。
- Release 必须记录 GHCR 不可变 manifest digest。部署 Compose 默认同时固定应用 manifest digest 和已验收 PostgreSQL 17 amd64 digest；版本更新必须显式修改，不跟随浮动标签。
- `infra/compose/compose.yaml` 仍是唯一运行契约；新增的发布 overlay 只替换镜像来源、拉取策略并挂载一次性 Owner 密码，不复制数据库、应用或安全配置。
- 凭据准备器只接受一个尚不存在的绝对目录，创建 `0700` 目录、相互独立的 `0600` 随机主密钥、三个数据库密码和 Owner 密码。值不得进入终端、参数、环境、日志、仓库或证据；环境文件只保存非秘密配置和受保护文件路径。
- 面向用户的部署命令必须提供 `pull`、`bootstrap`、`start`、`status`、`logs`、`stop` 与非破坏性 `down`。不提供自动删除卷命令，不读取或迁移旧数据。
- 默认只允许 `local` 模式、非 Secure Cookie 和 `127.0.0.1` 回环访问。域名、TLS 终止、跨主机数据库、HA、云存储和生产部署不在本次公开实测分发范围。
- README 只保留产品定位、状态、快速开始、功能、安全边界和文档入口；里程碑流水、ADR 清单和详细证据留在 `docs/`。

## 验收

1. 发布 Compose 的规范化结果只包含当前 Clean Slate 应用和 PostgreSQL，数据库不发布宿主端口，应用默认只绑定回环，现有只读根、capability、资源上限和 secret 文件边界不变。
2. 在全新 owner-only `/tmp` 目录中生成凭据，不泄露值；用现有候选镜像和临时 PostgreSQL 卷完成 provision、migration、Owner bootstrap、ready、登录、会话、退出和旧会话失效冒烟。
3. GHCR 回读的架构、manifest digest 与本地候选一致；公开包可匿名读取，Release 页面记录精确 digest、部署入口和当前限制。
4. 文档命令通过静态检查和实际冒烟；仓库、Git diff、终端摘要和发布说明不含凭据、临时路径、容器 ID 或原始业务数据。

## 后果

`v0.3.1` 成为可复现的单机公开实测版本，但仍不是生产稳定版。真实模型正确率、真实邮箱或 Provider 联调、TLS/域名、生产部署和多架构镜像继续是独立门禁。
