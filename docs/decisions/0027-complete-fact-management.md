# ADR-0027：完整单据管理、分页与详情

状态：已接受，B3 已本地验收
日期：2026-09-04

## 范围与唯一查询链路

按 B1～B6 已授权顺序，替换支付/发票固定前 200 条的列表，实现数据库 keyset 分页、现有字段筛选和完整只读详情。复用 B2 纠错、现有分配与 Fact 软删除，不建立第二份账单、金额缓存或前端全量集合；不新增记账类型、统计报表或旧格式兼容。

## 查询契约

- `GET /api/v1/payments`、`/invoices` 接收 `cursor`、`limit`、`date_from`、`date_to`、`q`、`allocation_status`。每个参数最多一次，未知参数拒绝；默认每页 20，范围 1～100。返回 `items` 和 `next_cursor`（末页空字符串），不提供未经统计的总数。
- Payment 日期使用持久化 `business_date`，Invoice 使用 `invoice_date`，起止日期各自可选、包含端点；非法日期与反向区间拒绝。日期不随浏览器时区变化。
- `q` 折叠空白、最长 200 字符，按字面子串搜索 Payment 商户/订单号和 Invoice 购销方/发票号；不把 `%`、`_` 或反斜杠当查询语法。分配状态为空或 `all`、`unallocated`、`partial`、`allocated`；含义沿用现有投影，零金额行为不另造规则。
- 固定按不可变 `created_at DESC, id DESC` 排序，界面明确“确认入库顺序”；可纠错的业务日期只用于筛选。游标携带排序元组与版本，绑定租户、类型和规范化筛选；不能要求锚点仍存在。新增记录通过刷新首屏查看，删除上一页末项不阻断后续页，日期纠错不使同一 ID 改变排序位置。
- 每页是当前一致性快照，不持有跨请求数据库事务；分页中改变筛选字段或分配状态的记录可能进入/退出结果，页面提示刷新获取最新集合，不承诺跨请求冻结结果。排序身份不变，已访问记录不能因日期纠错重复跨页出现。
- SQL 参数化，有界 `limit + 1` 取数，不使用 offset，不为每页拉取全量账单或明细。活动分配继续从 Link 聚合，限制当前租户/相关 Fact；发票列表仅返回当前 `item_count`，明细通过详情读取。

## 详情与权限

- 新增 `GET /api/v1/payments/{id}`、`/invoices/{id}`；统一详情 Envelope 含类型、当前完整业务投影、聚合版本、活动分配与当前行程摘要。发票详情包含当前 ReviewDecision 的全部明细，不混入历史明细。
- 详情在同一个只读 RepeatableRead 中读取字段、明细、关系和当前来源身份。`facts.read` 允许 Owner/Finance/Viewer 阅读正式字段；Reviewer 拒绝，跨租户与已删除返回不可见。
- 仅同时有 `review.source.read` 的账号收到原件/页码/Claim/Review 来源信息。Viewer 响应不含来源地址或原件标识，也不能调用现有下载端点。来源与审核仍由现有服务鉴权；不能用纠错工作区代替只读详情。
- 纠错要求 `facts.read` + `claims.review`，金额分配要求 `allocations.manage`；删除要求 `resources.delete`。界面逐项显示获授权动作，服务端独立拒绝越权。
- 删除复用 Fact DELETE：明确确认其将终止活动分配/归属，但保留来源和审核/报销历史；不使用未确认 Document 的物理删除入口，不新增清库/级联删除。

## 数据模型与升级

`0005` 只增加 Payment/Invoice 的租户 + 不可变入库时间 + ID 活动索引，保留现有数据、历史和现行查询所需索引。不改写 `0001`，不回填第二个排序字段，不迁移旧架构数据。详情是查询投影，不新增业务表或对象；既有精确备份对象集合不变。

## 页面与失败边界

- 列表统一分页/筛选状态，URL 保存已应用筛选与游标；从详情返回可恢复范围。显示本页数量、下一页/返回首屏，绝不把本页数量当总量。
- 应用新筛选或切换路由立即清除旧内容，以请求序号忽略迟到响应；失败不能显示错误范围的旧账单。重试使用失败请求的同一范围，不能悄悄跳回第一页。
- 详情展示完整字段/明细/关联状态，获授权原件预览与来源链接、纠错/分配/删除入口；404/错误清除前一条详情。删除成功返回刷新首屏，失败保留当前详情并明确提示。
- 加载、空、错误、无权限、键盘和窄屏均可操作，不为隐藏横向溢出裁掉操作列。

## 本地验收

- 两类各至少 201 条合成数据全部遍历，无重漏；同入库时间、锚点删除、新增、业务日期纠错与筛选变化均有明确结果，游标跨租户/类型/筛选拒绝。
- 日期、字面查询、购销方/订单号、分配状态、非法/重复参数及边界数量通过；查询有界、索引可用，发票列表不预载明细。
- 详情字段/明细与 B2 当前来源一致；四角色、跨租户和已删除边界通过，Viewer 不收到未授权来源内容。
- 实际浏览器完成筛选/分页/详情/原件入口与纠错/分配/删除，覆盖迟到响应、失败重试、键盘及响应式。
- `0005` 正常/重复升级和故障回滚、适用 Go/Web 全回归、契约/静态/构建及原有覆盖率门槛通过；只写安全聚合证据，不借用 B2 结果。

不包含用户实例升级、真实模型/外部联调、下载、提交或发布。重型验证串行，阶段结束回收本轮资源。
