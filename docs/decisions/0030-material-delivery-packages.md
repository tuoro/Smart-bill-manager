# ADR-0030：行程与报销材料交付包

状态：已接受并完成 B6 本地验收，尚未发布
日期：2026-09-05

## 范围与精确版本

本决策替代历史 M3 对业务导出的排除，仅增加当前行程或固定报销快照的 ZIP 交付包。不是认证备份、旧导出兼容、PDF 排版、外部同步或报表设计器；不增加导出业务表、迁移或另一份正式数据源。

- 当前行程：该 Trip 的全部活动 Payment/Invoice Assignment、活动 TripEvidence 关联，以及所含发票的活动辅助材料。不是页面当前一页、日期推荐或 PaymentInvoiceLink 推测扩张的集合。原件由不可变初始 Review → Claim → Document 定位；说明清单记录当前正式字段和当前 Review 身份。
- 固定报销：只使用 Reimbursement 的固定 Trip 字段、ReimbursementItem 字段/Review 身份及 reimbursement_material_snapshots；清单版本固定为提交快照版本 1，不引用会随状态决定递增的当前 Reimbursement 聚合版本。纠错、移动、删除、状态变更和当前发票材料不能重写历史文件集合或清单 hash。历史 `materials_captured=false` 与 `fact_review_decision_id=null` 明确标注未捕获，不能回填或假称已冻结当时的 Review。原件仍可沿不可变初始 Review 追溯，但不把初始 Review 冒充提交时版本。
- 报销从未冻结 TripEvidence 集合，因此固定报销包不含行程凭证；预览与包内说明明确披露。需要当前行程凭证时单独选择当前行程包。历史未捕获辅助材料允许导出已知原件，必须显式确认这个限制，不能称作完整历史辅助材料集。
- Owner/Finance 同时满足 `facts.read` 与 `review.source.read` 才能导出；报销包另需 `reimbursements.read`。Reviewer/Viewer 无完整包入口；HTTP 和应用边界均不能依赖 UI 隐藏。

## 清单、限制与文件内容

一次只读 RepeatableRead 事务读取有界完整清单，包含范围身份、字段版本、关系身份和精确 Document 身份/大小/SHA。数据库查询最多读取上限加一，超过就拒绝，不能按管理页的 200 条截断。确定性排序及 manifest hash 固定用户预览；准备时重新读取并比较，变化返回 409，要求重新预览。

每包最多 5,000 个业务引用、1,000 个不同 Document、去重后 512 MiB 原始文件、520 MiB 实际 ZIP。相同 Document 只写一个文件，多个业务引用保留；不跨租户按哈希合并。归档路径使用固定目录、序号、经过规范化的文件名及按已验证 MIME 确定的扩展名；不接受用户路径。ZIP 只含原件、辅助材料、`manifest.json` 与中文 `说明.txt`，不含数据库、内部存储键、原始 Claim/Provider 响应、凭据或日志。该下载包含用户选定的业务信息，不得作为仓库验收证据提交。

使用标准库 ZIP Store（原图片/PDF 不再压缩）和固定 32 KiB 缓冲逐个读写。准备每个对象时验证实际字节数与 SHA-256；任何缺失、读取失败或变化都关闭整个包，错误只带可定位的 Document 业务 ID，不暴露本地路径。数据库快照不替代文件可读性检查，不给文件操作增加全局锁。

## 准备、原生下载与回收

流程为小型 JSON 预览 → CSRF 保护的 POST 准备 → 浏览器原生附件 GET。前端不使用 ZIP Blob/arrayBuffer。准备最长 2 分钟；已有 HTTP 默认超时仅在该准备/下载处理器中显式调整，其他接口不变。

临时包存于既有持久化对象根目录下的 `export-spool/`，与权威 `objects/` 并列，不使用容器的 256 MiB `/tmp` tmpfs，不新增宿主挂载或可下载的静态目录。目录为 owner-only；文件创建为 0600 后立即 unlink，再写入已打开的文件描述符。磁盘不足明确失败，不转为内存缓存。进程退出由操作系统释放已 unlink 文件。启动只允许清理本实现固定前缀、普通、零字节的创建窗口残留；未知、非空、链接文件报错，不递归清扫用户文件。

每进程最多 2 个包，生成、等待和下载共同占用名额，最多约 1,040 MiB 临时磁盘。内存仅保存有界清单及临时文件句柄，不保存 ZIP 字节。准备完成才返回随机包 ID；句柄绑定 tenant/user/session，5 分钟内由同一有效会话领取一次。领取再次检查权限；ID 不是免鉴权链接。下载完成、断连或 10 分钟上限释放句柄；显式取消、过期、准备失败和服务关闭同样释放。不提供断点续传；下载失败重新预览准备。

准备后的包是用户已确认时点的不可变副本，不宣传为下载时的实时集合；后续普通业务修改不重写它。新请求须通过当前会话认证，角色/密码变化仍按 B5 撤销会话；已授权的在途下载按既有在途请求边界处理。请求结果丢失可能留下一个至多 5 分钟的未领取句柄，不能自动无限重试生成。

页面可取消准备，切换目标/关闭/卸载取消 JSON 请求并清掉旧预览，已拿到的未下载包调用取消入口。迟到响应不得覆盖新目标。409 保留范围但撤销旧确认，缺件显示业务 ID；只在准备成功后提供下载。点击仅表述“交给浏览器下载”，不声称保存完成；下载中的取消交给浏览器。

## 恢复与验收

export-spool 不是权威对象，不进入认证备份的精确对象集合。停机备份允许该空目录；存在未知残留须先人工核对，不能把临时包纳入备份。恢复创建空目录。无新增数据库表，不增加无意义迁移；现有连续前向升级链不变。

验收覆盖：两范围不混用、超过一页的完整清单、共享对象去重、纠错/移动/删除/材料变更后的固定快照、历史未捕获提示、四角色/跨租户/跨会话拒绝、预览冲突、缺件/损坏不返回成功包、文件名与各项上限、取消/过期/断连/服务关闭、磁盘有界与非内存 ZIP、备份恢复排除临时文件。保留既有覆盖率和关键不变量门槛，完成契约/单元/真实 PostgreSQL HTTP/构建/浏览器及失败转人工→纠错→行程→补充材料→报销→导出的完整合成旅程后才能验收。
