# 钉钉收单配置

把钉钉机器人接成一个收单入口：成员把支付截图或发票直接发给机器人，系统识别后在聊天里回卡片，改字段、处理重复件、分配和确认都在对话里完成。

这条路径只产生候选，正式财务记录仍然只能由人在确认那一步创建，与网页审核走的是同一套用例。连接器不是第二条写入路径。

前置条件：一个钉钉企业（内部应用需要企业管理员权限来创建），以及一个已经装好的 Smart Bill Manager。**不需要公网入站**——应用主动向钉钉发起一条出站长连接（Stream 模式），所以内网部署、没有域名、没有备案都能用。

## 一、在钉钉开放平台建应用

在 <https://open-dev.dingtalk.com> 用企业管理员账号登录。

1. 进入「应用开发 → 企业内部应用 → 创建应用」，填名称和图标即可，其余留默认。
2. 创建完成后进入应用详情，在「凭证与基础信息」里拿到 **Client ID（AppKey）** 和 **Client Secret（AppSecret）**。AppSecret 只在这里能看到，复制下来。
3. 进入「应用能力 → 机器人」，点「添加机器人」。名称和头像随意，这是成员在钉钉里看到的样子。
4. 机器人配置里把**消息接收模式**选成 **Stream 模式**。这一项是关键：选了 HTTP 回调就需要公网地址，本系统用的是 Stream。
5. 「消息预览图」是可选项，只影响机器人卡片在会话列表里的缩略图，不填不影响功能。
6. 保存后发布应用（「版本管理与发布」→ 发布上线）。未发布的应用机器人不会出现在企业里。

权限方面，内部应用的机器人默认就能收发单聊消息和下载用户发来的文件，通常不需要额外勾选。若检测时报权限不足，再到「权限管理」里补齐机器人相关权限并重新发布。

## 二、在系统里启用

以管理员登录，进入「系统 → 钉钉收单」。成员看不到这一页，配置连接器需要管理员权限。

1. 填入上一步的 AppKey 和 AppSecret，保存。AppSecret 用主密钥加密落库，界面之后只回显「已设置」，不再显示原值。
2. 点「检测」。系统拿这对凭据去换一次访问令牌，通过会显示「凭据有效」。检测失败时给出的是安全化的原因，不会把钉钉的原始报文贴出来。
3. 点「启用」。进程随即建立出站长连接。停用、换凭据、删除凭据都是即时生效的，不需要重启容器。

凭据按工作区保存，同一个 AppKey 不能同时被两个工作区使用。

修改凭据时 AppSecret 可以留空，表示沿用已保存的那一份；只想换 AppKey 时不必重新输入密钥。

## 三、成员绑定自己的钉钉账号

机器人不接受陌生人。每个要用的人各自绑定一次：

1. 成员登录网页，进入「账号与密码」，点生成绑定码。
2. **10 分钟内**把这串码直接发给钉钉机器人（单聊）。
3. 机器人回「已绑定」即可开始使用。绑定码一次性，用过即失效。

绑定建立的是「钉钉用户 ↔ 系统成员」的对应关系，之后机器人收到的每份单据都记在这个成员名下。未绑定的人发消息一律被拒收。

## 四、日常怎么用

把支付截图、发票图片或 PDF 直接发给机器人。识别完成后机器人回一张卡片，列出抽取到的字段，并按情况附上疑似重复件和可关联的候选。

对话里可用的回复：

| 回复 | 作用 |
|---|---|
| 编号（如 `3`） | 修改该编号对应的字段，机器人会追问新值 |
| `处理` | 逐项判断疑似重复件与可关联候选 |
| `确认` / `确定` / `保存` | 确认这份单据，生成正式记录 |
| `作废` / `丢弃` / `删除` | 作废这份单据，**同时删除原件** |
| `菜单` / `帮助` / `help` / `?` | 列出当前能做的事 |
| `漏票` / `缺发票` | 列出还缺发票的支付记录 |
| `待审核` / `待确认` | 列出正等待处理的单据 |

改字段时的写法有固定要求，回错了机器人会把正确格式告诉你：

- 金额写成 `12.34`，小数位不超过该币种精度；
- 日期写成 `2026-09-10`；
- 时间写成 `2026-09-10 12:30`，24 小时制，时区沿用单据原有时区，不在聊天里改；
- 整数和小数直接写数字。

还有待判断的重复件或候选时，直接回「确认」会被挡下来，先回「处理」走完逐项判断。

`作废` 在任何一步都能说，包括改字段改到一半。它会连原件一起删除，这是有意的取舍：不保留被拒绝件的审计原件。

## 五、边界与注意事项

**一人同时只有一份在办单据。** 上一份没确认或作废之前又发新文件，机器人会先提示你把手上这份处理完。这条限制让「编号」「确认」这类回复不会产生歧义。

**20 分钟提醒，30 分钟过期。** 卡片发出后没有回应，20 分钟时提醒一次，30 分钟后这份单据退出对话状态，需要到网页里继续处理，记录不会丢。

**文件类型看字节不看文件名。** 钉钉给的文件名不作数，系统按实际字节判断是不是合法的 JPEG、PNG、WebP 或 PDF。

**同一份文件不会重复入库。** 同工作区内按内容摘要去重，重复发送会被告知已经收到过。

**权限按成员真实角色。** 聊天里能做的事不超过这个人在网页里能做的事，连接器不放大任何权限。

**发送者以钉钉的企业内稳定 userid 为准**，改昵称、换头像都不影响已建立的绑定。

## 六、排查

| 现象 | 多半是 |
|---|---|
| 发消息机器人不理 | 应用没发布，或消息接收模式不是 Stream |
| 回「还没绑定账号」 | 这个钉钉账号没绑，或绑定码过期了（10 分钟） |
| 回「绑定码属于另一个工作区」 | 用了别的工作区生成的码 |
| 检测失败 | AppKey/AppSecret 不匹配，或应用未发布 |
| 传了文件没反应 | 看应用日志里有没有出站连接建立的记录；出站被防火墙拦住时连接建不起来 |
| 回「这份单据已经不在等待状态了」 | 会话已过期，或这份单据在网页里已被处理 |

连接状态和最近一次检测结果在「系统 → 钉钉收单」页上可以看到。
