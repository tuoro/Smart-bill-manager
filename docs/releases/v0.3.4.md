## 范围与失败边界

发布当前已确认的全站 UI、主题、导航、底部折叠和手机抽屉修订。仅涉及 Web、相应测试、离线构建资源限制和发布文档；不改变 API、数据库 Schema、AI 契约、金额、审核、分配、权限或持久化格式。配置读取和操作错误分别展示，任何已有人工确认门禁不得放宽。

使用下一补丁版本 `v0.3.4`，保持 `linux/amd64` 单机公开实测预发布。分发包含新应用镜像、固定 digest 清单、源码 Tag、Docker Bundle 和 SHA-256；旧版本与 `latest` 不变。只做远端分发，不升级用户正在使用的本地实例，不读写其业务数据或真实 Provider 配置。

## 本次验收

- 完整 Web 单元、类型、lint、格式、生产构建和当前 8 个 spec 的全部 73 项浏览器场景；不得跳过真实本地 synthetic API 的四个代表流程，或只用页面 Mock 替代完整流程。
- 新镜像离线构建、输入摘要、必需/禁止资产、工具链缺席、Compose 隔离和资源限制；本轮 Go 构建固定 `GOMAXPROCS=2`、`-p=1`，重型工作串行。
- 新隔离数据库上的 Owner 初始化、运行时认证、纯 synthetic Provider 上传与人工审核；不连接真实模型、邮箱或远程数据库。
- 四个代表页面各三次 Lighthouse（Performance >= 85、Accessibility >= 95）、既有响应式/回流/键盘/深色门禁及新增导航交互。所有原始报告只保存在本轮 owner-only `/tmp` 目录。
- 常驻侧栏占用工作区后，审核页在小于 1024px 时为单列、1024–1439px 为双列、1440px 起为三列；登录键盘顺序包含新增主题按钮，完整检查跳转链接、品牌、主题、邮箱、密码、显隐与提交七个焦点。横向溢出、焦点可见、表单标签和错误绑定门槛不变。
- 部署工具测试、13 文件确定性 Bundle、SHA-256、版本引用、完整 diff、敏感信息、大文件、临时资源与远端发布回读。

未变更的后端、数据库、备份恢复和性能实现沿用既有 M4 历史证据；不把历史 10,000 数据性能、50 Job 内存或 1,000 Document 恢复结果改绑为新镜像，不宣称本次重跑了这些门禁。若发现相关实现变化或新的后端故障，应停止当前补丁发布并重新界定受影响验收。
