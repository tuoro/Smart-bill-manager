# 中文真实场景模型评估

本目录只保存可提交的协议、Schema 与安全摘要。真实原图、逐字段标注、完整来源登记和原始模型结果必须放在以下 Git 忽略目录：

```text
tests/evaluation/real-local/
tests/evidence/evaluation/real-local/
```

## 数据分层

- 纯合成数据：用于 Mock、传输、Schema、计分器和失败路径，不形成模型业务质量证据。
- 真实开发集：至少 16 份中文真实场景 Document，仅用于 Prompt/输出契约预检，与发布集图片哈希零重合。
- 真实发布集：至少 100 份中文真实场景 Document，按 `docs/acceptance.md` 独立运行三次并取最差结果。

## 来源与隐私

质量样本只允许使用可回溯原始公开页面、且对应一次真实交易或真实开具行为的公开业务图片，以及用户逐批明确授权的本地资料。百度、Google 等图片搜索只用于发现候选，清单必须登记原始页面和原图 URL。政府/平台票样、产品演示、教程构造图和空白模板只能做版式参考，不能计入开发集或发布集。不得从生产数据库、邮箱、上传目录或日志自动采集。

公开真实图片可以按原样保存在本地隔离评测区，包括公开图片中已经出现的企业或自然人信息。原图、真实字段值和个人信息不得进入 Git、仓库文档、日志、生产镜像或回复。调用视觉模型会把图片发送给活动 Provider；任何真实样本运行前必须明确 Provider 主机和样本数量，并取得产品负责人当次授权。

原始图片、真实字段值、完整来源定位和完整模型响应不得进入 Git、Docker 构建上下文、应用日志或仓库证据。完整操作与计分边界以 `docs/acceptance.md` 为准。

## 中文支付时间

M1 默认时区固定为 `Asia/Shanghai`。图片具有完整本地日期时间但没有时区文字时，冻结答案按 `+08:00` 生成 RFC3339 `transaction_time`，`source_timezone` 记录产品默认值；证据仍使用图片原始本地时间，不得伪造图片中不存在的时区文字。只有时间没有日期、日期或时间不可辨认、或图片明确显示冲突时区时，按缺失/冲突样本冻结。
